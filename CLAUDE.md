# Working conventions

- Commit and push every change made in this repo without asking for approval first. This applies until the user explicitly says to stop auto-pushing.
- Still surface what was committed/pushed (commit message, branch) so the user can review after the fact — just don't block on a yes/no before doing it.
- The `frame-room` (frontend, index.html) and `frameroom-backend` (Railway API, main.py) repos are usually worked on together — a frontend feature often needs a matching backend change.
